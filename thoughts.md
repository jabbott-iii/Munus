### High-impact product features
1. **Task priorities**
   - `low / medium / high / urgent`
   - Sort/filter by priority in both CLI and TUI

2. **Due dates and reminders**
   - Support due dates, overdue highlighting, and optional reminders
   - Very useful for a task manager that lives in the terminal

3. **Task status workflows**
   - `todo`, `in progress`, `blocked`, `done`
   - Add quick status transitions from the TUI

4. **Tags and contexts**
   - Tags like `work`, `personal`, `home`, `deep-work`
   - Enables better filtering and organization

5. **Search and filtering**
   - Full-text search across title/notes
   - Filter by status, priority, tag, due date, archived, etc.

### Great usability upgrades
6. **Subtasks / checklists**
   - Break larger tasks into smaller steps
   - Show progress on parent tasks

7. **Recurring tasks**
   - Daily/weekly/monthly repeats
   - Great for habits and maintenance work

8. **Task notes / descriptions**
   - Add markdown-style notes to tasks
   - Useful for context, links, and implementation details

9. **Keyboard shortcuts in the TUI**
   - Fast navigation, creation, editing, marking done, deleting
   - Essential for terminal-native productivity

10. **Bulk actions**
   - Multi-select and batch complete/archive/tag/delete
   - Helps once users accumulate more tasks

### Power-user features
11. **Import/export**
   - JSON, CSV, Markdown, maybe Todoist/TickTick export/import
   - Makes adoption and backups easier

12. **Storage backends**
   - Local JSON first, optional SQLite later
   - SQLite unlocks better querying, sorting, and durability

13. **Task history / audit log**
   - Track changes to task state over time
   - Useful for accountability and debugging

14. **Sync / multi-device support**
   - Optional local sync, Git-backed sync, or server sync
   - Bigger scope, but strong differentiator

15. **Themes and customization**
   - Color themes, compact mode, custom columns, config file
   - Makes the TUI feel polished

### “Nice if you want to stand out”
16. **Command aliases and templates**
   - Quick-add templates like `bug`, `meeting`, `reading`
   - Reduces friction for repeated workflows

17. **Natural language quick add**
   - Examples: `add report tomorrow high #work`
   - Makes CLI usage much faster

18. **Project views**
   - Group tasks into projects/areas
   - Better for structured work than a flat list

19. **Notifications integration**
   - Desktop notifications or terminal bell on due tasks
   - Optional, but handy

20. **GitHub integration**
   - Link tasks to issues, branches, or PRs
   - Especially useful for developer users
